# Brand

- `logo.svg`, `logo-on-dark.svg`: the wordmark. The hyphen is the end-of-proof square.
- `icon.svg`, `icon-dark.svg`: app icon, `m■h`. `avatar.png`: 460 px avatar.
- `favicon.svg`: 16 px favicon, `m■`, switches colours with `prefers-color-scheme`.
- `banner.svg`, `banner-dark.svg`: README banner.

Colours: paper `#F2EFE8`, ink `#121212`, safety orange `#FF5A1F`. Type: Geist Medium, outlined to paths, so no font is needed to render these files. Geist is licensed under the SIL Open Font License 1.1.
